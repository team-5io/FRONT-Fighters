## 1. 진단 — 상자를 없앴는데 왜 아직 바빴나

4차까지 컨테이너를 477 → 323개로 줄였는데도 캡처는 여전히 바빴다.
**컨테이너 개수와 난잡함이 같은 것이 아니기 때문**이다. 지시서가 짚은 다른 세 축은
지금까지 어느 라운드도 재지 않았다.

| 축 | 이번에 측정한 값 (before) |
| --- | --- |
| 동시에 켜진 레이아웃 구역 | 문서 목록·그래프·작성 = **2구역** (작성은 + 하단 플로팅) |
| 보조 패널 하나의 정보 그룹 | 문서 목록 **3개** · 그래프 **4개** 동시 펼침 |
| 화면마다 반복되는 부차 정보 | "내 역할 — 할 수 있는 것" 배너가 **3화면**에 반복 |

컨테이너를 더 지워서는 이 셋이 안 줄어든다. 이번엔 **레이아웃 구조**를 손댔다.

## 3. 원칙별 적용

### 원칙 C — 반복되는 권한 안내를 내렸다 (가장 먼저)

`MyRoleBar` 전체 폭 배너를 문서 목록·Doc PR 목록·문서 작성에서 제거하고
**`RoleChip`**(신규)으로 대체했다 — 상시 노출은 칩 하나, 할 수 있는 것·보이지 않는
것·팀 관리자 여부는 hover/클릭 팝오버.

`MyRoleBar`는 **지우지 않았다.** 이 정보가 화면의 주인공인 곳(RACI 역할 관리,
마이페이지, Doc PR 상세)에는 그대로 쓴다 — 원칙 C는 "반복되는 부차 정보"에만 적용된다.

### 원칙 B — 보조 패널도 "주인공 하나"

| 화면 | 기본 노출 | 접거나 탭으로 내린 것 |
| --- | --- | --- |
| 문서 목록 | 제목·상태·설명·담당·번역본 | 최근 변경 · 연결된 Doc PR (`Disclosure`) |
| Document Graph | 노드 제목·상태·액션 2개 | 영향받는 문서 · 쓰는 곳 · 담당 (**탭 3개, 하나만 열림**) |
| 문서 작성 | (없음 — 본문이 주인공) | 연결된 문서 (`Disclosure`) |

문서 목록의 언어 태그는 제목 옆에서 속성 줄로 옮겨 밀도를 낮췄다(표 안에서는 유지).

### 원칙 E — 작성 화면 툴바

클릭 요소 5개가 한 줄에 몰려 있던 것을 이렇게 바꿨다.

```
before : [관련 문서 연결] [번역 보기] [작성 도우미]        [초안 저장] [Doc PR 생성]
after  : ⋯ 더보기   방금 전 저장됨                                    [Doc PR 생성]
```

- 부속 액션 3개는 `⋯ 더보기` 메뉴로 묶었다.
- **`초안 저장` 버튼은 없앴다** — 자동 저장되는 동작이라 "방금 전 저장됨" 상태
  텍스트로 충분하다(지시서가 검토하라고 한 항목).
- 채운 버튼은 `Doc PR 생성` 하나뿐이다.

### 원칙 D — 대시보드 통계 줄

보라 배지 + 검정 + 주황 + 파랑이 섞여 있던 줄에서 **강조를 하나만 남겼다** —
"내가 처리할 일 2"만 브랜드색이고 나머지는 전부 같은 회색조 mono다.

### 원칙 F — 아이콘 어휘표

[`docs/icon-system.md`](icon-system.md) 신설. 상태 점·RACI 원·언어 태그·AI 마커·
잠금·판단 주체 칩·사이드바 아이콘·블록 에디터 마커를 표로 고정하고, **"쓰지 않기로
한 것"**(아이콘 타일, 장식 아이콘, 상태색 면 배경)도 함께 적었다.
새 종류는 만들지 않고 이미 쓰던 것만 정리했다.

## 4. 스크린샷 대조

이번 라운드는 진단 자체가 스크린샷에서 나왔으므로 검증도 스크린샷으로 마무리했다.
5장을 before/after로 남겼다 (`대시보드 · 문서 목록 · Doc PR 목록 · Document Graph ·
문서 작성`).

눈에 띄는 변화:
- **문서 작성** — 상단이 `뒤로가기 / 브레드크럼 / 제목 / 속성 줄 / 툴바 한 줄`로
  정리되고 우측 패널이 접힌 줄 하나가 됐다. 본문 캔버스가 확실히 주인공이 됐다.
- **문서 목록** — 배너가 사라진 만큼 표가 위로 올라왔고, 우측 패널이 "요약 + 접힌
  두 줄"로 짧아졌다.
- **Document Graph** — 우측이 세 그룹 동시 펼침에서 탭 하나로 바뀌어 캔버스와
  경쟁하지 않는다.

## 6. 판단이 필요했던 지점

1. **`MyRoleBar`를 삭제하지 않았다.** 세 화면에서 뺐지만 컴포넌트는 남겼다. RACI
   역할 관리·마이페이지·Doc PR 상세처럼 권한이 화면의 주인공인 곳에서는 배너가
   맞는 형태다. 지시서도 원칙 C를 "반복되는 부차 정보"로 한정했다.

2. **Document Graph 패널은 접기가 아니라 탭으로 했다.** 지시서가 "탭 두 개로 분리
   하거나 둘 다 접어서"라고 선택지를 줬는데, 세 그룹(영향·사용처·담당)이 전부
   "이 노드에 대한 다른 관점"이라 탭이 더 맞았다. 접기로 하면 셋 다 닫힌 상태가
   기본이 되어 패널이 빈 채로 남는다.

3. **작성 화면 우측 패널이 접힌 줄 하나만 남았다.** 원칙 B를 그대로 따른 결과인데,
   패널 폭(260px)에 비해 내용이 적어 여백이 크게 남는다. 본문이 주인공이라는
   의도에는 맞지만, 패널을 아예 없애고 접힌 줄을 툴바 옆으로 옮기는 것도 대안이다 —
   이번엔 지시서 원칙 A(본문 + 보조 패널 2구역 허용)를 따라 패널을 유지했다.
