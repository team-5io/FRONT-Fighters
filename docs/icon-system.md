# 아이콘·마커 어휘표

> 5차 정상화 지시서 원칙 F. **새 화면을 만들 때 여기 없는 마커를 즉흥적으로 추가하지 않는다.**
> 새 종류가 정말 필요하면 이 표에 먼저 추가하고 근거(무엇을 구분하는가)를 적는다.

화면마다 다른 규칙으로 등장하던 마커를 한곳에 고정한 표다. 각 마커는
**"무엇을 구분하는가"가 서로 겹치지 않아야** 한다 — 겹치면 둘 중 하나를 없앤다.

---

## 1. 상태 마커

| 마커 | 형태 | 의미 | 정의 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| 상태 점 | 6px 색 원 + 텍스트 | Doc PR / 문서 상태 | [`status.js`](../src/data/status.js) | 목록·표·이력 (`StatusBadge variant="inline"`) |
| 상태 알약 | 테두리 + 틴트 배경 | 위와 같음 | 〃 | 상세 화면 헤더 속성 줄만 (`variant="solid"`) |

색은 상태별로 고정이다 — `neutral` 생성/초안 · `info` AI 리뷰 · `main` 사람 리뷰/리뷰중 ·
`warning` 재제출/리뷰어 지정 필요 · `error` 반려 · `success` 확정/공식.

## 2. 역할 마커

| 마커 | 형태 | 의미 | 정의 |
| --- | --- | --- | --- |
| RACI 원 | 16~20px 색 원 안에 R/A/C/I 글자 | 그 사람의 문서 권한 | [`raci.js`](../src/data/raci.js) |
| RACI 알약 | 원 + 이름 + 테두리 | 위와 같음 | `RaciChip variant="solid"` |
| 내 역할 칩 | RACI 원 + 라벨 + 팝오버 | **현재 사용자**의 역할 | `RoleChip` |

색: **R=info · A=main · C=warning · I=neutral** (DESIGN.md 2장).
Figma가 R/A를 뒤바꿔 쓴 것은 오류였고 1차에서 바로잡았다 — 되돌리지 말 것.

## 3. AI 마커

| 마커 | 형태 | 의미 |
| --- | --- | --- |
| CIO 마크 (✦) | 4각 스파크, `info` 색 | 이 산출물은 CIO(AI)가 만들었다 |
| CIO 배지 | 마크 + `CIO · 기능명` | AI 산출물의 주체 표기 |
| info 좌측 띠 | 3px 세로/가로 선 | 이 카드 전체가 AI 산출물 |

**개별 AI 기능명(DocumentLion 등)을 주체로 내세우지 않는다.** 주체는 항상 CIO이고
기능명은 배지의 부제로만 쓴다 (기능명세서 1장 — 단일 AI 정체성).

## 4. 그 밖의 마커

| 마커 | 형태 | 의미 | 쓰는 곳 |
| --- | --- | --- | --- |
| 언어 태그 | 지구본 + `EN·JA` | AI 번역본이 있는 언어 | 문서 목록 표, 문서 요약 속성 줄 |
| "AI 번역" 라벨 | 지구본 + 텍스트 | 이 콘텐츠는 AI 번역이다 (기능명세서 4.1 **필수**) | 번역 보기 |
| 잠금 | 자물쇠 | RACI 열람 권한 없음 — 제목·관계가 숨겨짐 | 그래프 노드, 영향 문서 목록 |
| 판단 주체 칩 | `CIO` / `사람` / `조직` / `시스템` | Merge 차단 사유를 누가 판단했는가 | 대시보드, Doc PR 상세 |

## 5. 내비게이션 아이콘 (사이드바)

| 아이콘 | 항목 |
| --- | --- |
| 집 | 대시보드 |
| 문서 | 문서 |
| 별 | Doc PR |
| 꺾은선 | 그래프 |
| 연필 | 작성 |
| 톱니 | 설정 |

사이드바 아이콘은 **내비게이션 전용**이다. 본문 안에서 같은 아이콘을 장식으로 쓰지 않는다
(3차 지시서 2.6 — 아이콘은 상태·유형을 나타낼 때만).

## 6. 블록 에디터 마커

| 마커 | 의미 |
| --- | --- |
| `▶` / `▼` | 토글 블록 접힘 / 펼침 (`>` + 스페이스로 생성) |
| `•` | 글머리 기호 목록 |
| `1.` | 번호 매기기 목록 |
| 체크박스 | 할 일 블록 |
| 좌측 3px 회색 선 | 인용 블록 (`"` + 스페이스로 생성) |
| 옅은 배경 + 언어 라벨 | 코드 블록 (``` 를 치는 즉시 생성 · 번역 시 원문 보존 대상) |
| 가로 실선 | 구분선 (`---` 를 치는 즉시 생성) |

## 쓰지 않기로 한 것

- **아이콘 타일**(색 배경 사각형 안에 아이콘) — 3·4차에서 전부 제거했다. 아이콘은
  타일 없이 텍스트 옆에 둔다.
- **장식용 아이콘** — 정보를 구분하지 않는 아이콘은 넣지 않는다.
- **상태색 면 배경** — 상태색은 위 1·2번 마커 안에서만 쓴다 (3차 지시서 2.2).
