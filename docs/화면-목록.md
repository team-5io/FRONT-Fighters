새 화면을 만들면 여기에 한 줄 추가한다 (`CLAUDE.md`의 "작업 순서" 참고).

- Figma 파일: [멋사_해커톤][figma] (키 `3b2rJKtZ93aTpcKMlYGuuo`)
- 로컬 확인: `npm run dev` → `localhost:5173` + 아래 경로
- 라우팅: `src/App.jsx`의 `ROUTES` 해시 맵. 매칭 안 되는 해시는 로그인으로 폴백.

## 화면 간 이동

실제로 연결된 링크는 아래 둘뿐. **사이드바 내비게이션을 포함한 나머지 링크·버튼은
`href="#"` 자리표시** 상태라, 지금은 주소창에 해시를 직접 입력해야 이동한다.

- 로그인 → `팀 생성 또는 참여` → `#/team-invite`
- 팀설정 초기화 → `팀 생성 또는 참여로 돌아가기` → `#/team-invite`

## 화면별 메모

Figma 대비 실측 오차와 1차 구현에서 판단이 필요했던 지점.
UX 관점의 후속 과제는 [2차-UX-패스-체크리스트.md](2차-UX-패스-체크리스트.md) 참고.

**1. 온보딩/로그인** — 1440×1024, 세로 좌표 전부 일치.
카드가 Figma상 본문 중앙에서 30px 왼쪽이라 정중앙으로 옮김.

**2. 팀생성/참여** — 1440×1024, 최대 오차 2.3px.
통계 3열은 `justify-between`이 Figma 좌표와 산술적으로 일치.
`플랜` 값이 Figma에 비어 있어 빈 칸으로 둠. `거절 하기`는 DS에 없는 변형(회색 채움 + 2px 테두리).

**3. 팀설정 초기화** — 1440×1024, 최대 오차 1.5px(패널 아이콘 가로 중심).
본문이 가운데 정렬이 아니라 좌측 348px 고정, 폭 1015px.
패널·입력 반경 2px 때문에 `borderRadius.xs` 토큰 신설.

**4. 대시보드(홈)** — 1440×1972, 주요 랜드마크 전부 일치.
Figma에서 같은 열의 카드 x가 348/351/355/860/865/869로 흔들려 좌측 348 / 우측 860 / 폭 487로 정렬(최대 편차 ~11px).
오탈자 3곳 교정(진행 현항→현황, 온보딩 플로우 전책→정책, 재체→대체 지정).
사이드바 선택 상태(`activeNav`)를 여기서 처음 도입.

**5. 문서 목록** — 1440×1024, 최대 오차 ~2px.
상태 배지는 폭이 달라도 가로 중심(x≈859)을 맞추는 배치.
본문 텍스트가 전부 스켈레톤 바(`#D9D9D9`) — 실제 문구 미정.
Figma 노드 `23:762`(2행에 홀로 뜬 `>`)는 작업 잔여물로 보고 제외.

**6. Doc PR 목록** — 1440×1024, 배지 중심 1125로 정렬, 최대 오차 ~3px.
검색·필터 줄은 문서 목록과 공용([ListFilterBar][c1]).
오탈자 4곳 교정(셍성→생성, 게이트 웨이→게이트웨이, 데이터 베이스→데이터베이스, 메뉴얼→매뉴얼).
`반려` 배지만 테두리 규칙이 달라 다른 배지와 같은 규칙(`error/40`)으로 맞춤.

**7. Document Graph** — 1440×1996, 타이틀 x(−2px)를 뺀 모든 좌표 일치.
이 프레임만 카드 좌측이 346(다른 화면은 348) — 카드 기준 346에 맞춤.
오탈자 1곳 교정(시각하할→시각화할).
Figma 2행에 배지 두 장이 완전히 포개져 있어(아래 `AI 리뷰중` `22:236`, 위 `간접 영향` `22:242`) 보이는 쪽만 구현.
`[비공개 문서]`의 "영향 권한이 없습니다"는 권한 안내 카드의 "열람 권한"과 어긋나지만 의도일 수 있어 원문 유지.

**8. 문서 작성/편집** — 1440×1024, 최대 오차 4px(`연결된 문서` 2행·구분선).
좌우 컬럼 시작 높이가 다르다(좌 228 / 우 267). 하단 액션 버튼은 좌측 첨부/번역 버튼과 같은 y(921)에
놓이도록 우측 컬럼 안에 뒀다.
`Ai 구조 추천` 본문이 스켈레톤 바 — 실제 문구 미정.
Figma 노드 `23:783`(`본문` 라벨)이 에디터 안내문과 겹쳐 가려져 있어 제외.

**9. AI 구조 추천** — 1440×1024, 최대 오차 4px(`편집` 배지 1개).
사이드바 선택은 `작성`(작성 화면의 하위 흐름).
Figma에서 섹션 카드가 두 장 겹쳐 있어(530px `25:830` 아래, 648px `25:832` 위) 보이는 648px만 구현.
막대 2개짜리 카드만 첫 막대 간격이 좁다(10 vs 17) — 110px 안에 두 줄을 넣어야 해서로 보고 그대로 반영.
`적용 전 확인` 본문에 "빅 섹션" 표기가 남아 있다(원문 유지).

**10. 관련 문서 연결** — 1440×1024, 최대 오차 3px(하단 버튼 · 우측 끝 정렬).
사이드바 선택은 `작성`. 좌측 419(카드 2장) + 13 + 우측 618.
오탈자 3곳 교정(문설르→문서를, 표사 됩니다→표시됩니다, 가이드 라인→가이드라인).
`연결 미리보기`의 화살표가 1행(문서명)과 4행(관계명)에만 붙어 있다 — 원본 그대로.
Figma에 `연결된 문서` 라벨이 두 장 겹쳐 있어(`26:941`/`26:947`) 한 장만 구현.

**11. 번역 보기** — 1440×1344, 최대 오차 4px(입력창 안 자리표시 막대).
사이드바 선택은 `작성`. 카드 폭은 1052로 통일(Figma는 `원문 유지 영역`만 1046).
저장 버튼 라벨이 `연결 저장`이다 — 관련 문서 연결 화면에서 복사된 것으로 보이나 원문 유지.
번역문에 **"AI 번역" 라벨이 없다** (CLAUDE.md 필수 요구 — 2차 패스 항목).
Figma에 `원문` 제목이 두 장 겹쳐 있어(`26:1048`/`26:1052`) 한 장만 구현.

**12. Doc PR 상세** — 1440×2232, 최대 오차 2px. 카드 7장(요약 1033 전폭 + 2단 504×6).
요약 카드 5개 열은 라벨/값이 열마다 가운데 맞춤인데 열 폭이 제각각이라
Figma 열 중심(491/661/823/1005/1204)을 재현하는 고정폭 배열로 구현.
오탈자 1곳 교정(브렌치→브랜치).
Figma에 `김재원 · 리뷰어` 라벨이 두 장 겹쳐 있어(`41:70`/`41:131`) 한 장만 구현.
**AI 리뷰와 사람 리뷰가 별도 카드로 분리된 첫 화면** — 다만 "참고용, 최종 결정은 A 역할"
안내는 없다(2차 패스 항목).

**13. AI 리뷰 결과** — 1440×1812, 최대 오차 4px. 카드 5장.
⚠︎ **사이드바 선택이 Figma에서 `설정`으로 그려져 있다.** Doc PR 상세의 `상세 보기`에서
들어오는 화면이라 `Doc PR`이 맞아 보이지만 원본을 따랐다 — 확인 필요.
카드 머리(타일 38px + 24px 제목)가 세로 중앙이 아니라 타일 기준 +2px이고
타일↔제목 간격도 카드마다 17/24/26으로 달라 `CardHead`에 gap을 파라미터로 뺐다.
배지 폭이 같은 톤 안에서도 72~124로 제각각이라 Figma 폭을 데이터로 들고 간다.
`AI 리뷰 요약`의 안내 2줄이 Figma에서 빈 줄 때문에 카드 밖으로 넘쳐서, 붙여서 카드 안에 넣었다.
