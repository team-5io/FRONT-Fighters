## 미구현

## 화면 간 이동

정상화 이후 **사이드바를 포함한 주요 이동 경로가 모두 연결됐다** (1차에서는 전부
`href="#"` 자리표시였다).

- 사이드바: 대시보드 / 문서 / Doc PR / 그래프 / 작성 + 하단 설정(하위 5개 트리)
- 대시보드 → 각 지표·차단 사유 → 해당 목록 화면
- 문서 목록 → 연결된 Doc PR → Doc PR 상세
- Doc PR 목록 → Doc PR 상세 → CIO 1차 검토 / 승인권자 지정
- 문서 작성 → 관련 문서 연결 / 번역 보기 / 구조 추천
- 설정 → RACI · Charter · 용어집 · 팀원 관리 · 팀 설정 초기화
- 승인권자 지정 ↔ 팀원 관리 (Doc PR 단위 ↔ 팀 단위)

## 화면별 메모

> 아래는 **1차 구현(Figma 픽셀 재현) 당시의 실측 기록**이다. 정상화로 좌표 기준이
> 폐기되었으므로 현재 화면과 일치하지 않는다. 원본 디자인에서 무엇이 어긋나 있었는지의
> 이력으로만 남겨 둔다. 정상화에서 실제로 무엇을 고쳤는지는 각 페이지 상단 주석과
> `Doc-PR_화면정상화_지시서.md` 8장 완료 기준을 참고할 것.

Figma 대비 실측 오차와 1차 구현에서 판단이 필요했던 지점.
UX 관점의 후속 과제는 [2차-UX-패스-체크리스트.md](2차-UX-패스-체크리스트.md) 참고.

**1. 온보딩/로그인** — 1440×1024, 세로 좌표 전부 일치.
카드가 Figma상 본문 중앙에서 30px 왼쪽이라 정중앙으로 옮김.

**2. 팀생성/참여** — 1440×1024, 최대 오차 2.3px.
통계 3열은 `justify-between`이 Figma 좌표와 산술적으로 일치.
`플랜` 값이 Figma에 비어 있어 빈 칸으로 둠. `거절 하기`는 DS에 없는 변형(회색 채움 + 2px 테두리).

**3. 팀설정 초기화** — 1440×1024, 최대 오차 1.5px(패널 아이콘 가로 중심).
본문이 가운데 정렬이 아니라 좌측 348px 고정, 폭 1015px.
패널·입력 반경 2px 때문에 `borderRadius.xs` 토큰 신설.

**4. 대시보드(홈)** — 1440×1972, 주요 랜드마크 전부 일치.
Figma에서 같은 열의 카드 x가 348/351/355/860/865/869로 흔들려 좌측 348 / 우측 860 / 폭 487로 정렬(최대 편차 ~11px).
오탈자 3곳 교정(진행 현항→현황, 온보딩 플로우 전책→정책, 재체→대체 지정).

**5. 문서 목록** — 1440×1024, 최대 오차 ~2px.
